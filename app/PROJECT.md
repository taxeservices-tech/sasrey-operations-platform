# SASREY Operations Platform

## Mission

Build a world-class taxi and tours management platform for
SASREY Taxi Services & Tours Limited.

---

# Development Rules

1. One complete component at a time.
2. Every component must compile before moving on.
3. Git commit after every completed feature.
4. Never patch multiple files blindly.
5. BookingContext is the single source of truth.
6. Clean, readable TypeScript only.

---

# Git Workflow

git add .

git commit -m "Completed <Feature Name>"
